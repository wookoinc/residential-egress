# 可复制的住宅出口部署

范围：macOS 12+ 客户端（Clash Verge Rev）、Ubuntu 22.04/24.04 或 Debian 12 VPS、macOS 12+ 住宅节点；amd64/arm64。用户提供 VPS 和住宅电脑，脚本不能替代云防火墙授权、macOS 管理员授权或住宅节点持续在线。

一个 `./setup.sh` 入口：生成部署 → 分发角色目录 → 各端一条安装命令 → 验收。生成器 Python 3.9+ 标准库及 OpenSSL 1.1.1+；安装器使用独立目录、系统服务和锁定版本的 sing-box。每个部署创建独立 WG、Reality、SS、HY2 密钥，输出目录权限 0700、秘密文件 0600。角色目录仅含本角色需要的秘密。

HY2/BBR 和 Reality 共用一个专用 VPS 服务；唯一业务出站为绑定 WG 接口的 SS。住宅端只路由 VPS 的 WG /32，不更改默认路由。Clash 规则国内/私网直连，其余走只含两条住宅路径的 select 组。住宅故障不得回落到 VPS 或客户端公网。

安装只支持全新部署，拒绝覆盖已有路径、端口冲突；重复安装相同部署返回现状，不隐式更新。失败撤销本次服务和文件，卸载只处理自己的资源。依赖包和云防火墙由用户独立管理。运行现有生产服务不属于本次开发验收范围。
